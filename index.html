Installer

  • Application Windows : lance l'installateur. À la première installation, Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même. Les mises à jour suivantes s'installent ensuite toutes seules, vérifiées par la signature de l'auteur ; élèves, résultats et voix sont gardés.
  • Dans Ma classe (application Windows) : décompresse l'archive, puis Applis › Réglages › Ajouter une appli (dossier) et choisis le dossier syllamons. Pour mettre à jour, ajoute le nouveau dossier de la même façon : les données restent dans Ma classe/Applis/syllamons/donnees.
  • Navigateur (tablette, autre ordinateur) : la page Syllamons.html s'ouvre dans Edge ou Chrome.
